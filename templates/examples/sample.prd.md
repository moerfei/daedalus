# PRD：订单管理系统（proto-kit 冒烟样例）

## 背景
一个极简的内部订单管理系统，两类用户角色共用。本 PRD 用于端到端验证原型生成流水线。

## 页面

### P1 登录页
- 用户输入用户名、密码（均必填），点击「登录」进入订单列表
- 表单校验失败时提示，不允许跳转
- 登录成功后记录登录态

### P2 订单列表页
- 顶部导航：系统名「订单管理」+ 当前用户名 + 「退出」按钮（退出后清除登录态回登录页）
- 订单按状态筛选：全部 / 已支付 / 待支付（Tab 切换）
- 每行订单展示：单号、名称、金额、状态徽章；点击行打开「订单详情」弹窗
- 弹窗可关闭

## 数据实体
- Order：id（单号）、title（名称）、amount（金额）、status（状态：paid/pending）
- User：name、role

## 风格
简洁后台风格：蓝色主色（#2563eb）、浅灰背景、白卡片、8-12px 圆角。
